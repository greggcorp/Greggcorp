This website runs on [Jekyll](https://jekyllrb.com/), using a very Frankensteined version of the [Joseph](https://jekyllthemes.io/theme/joseph-blog-jekyll-theme) theme by Artem Sheludko. The site is compiled and deployed by [Netlify](https://www.netlify.com/).

I used Claude Code to customize components of this site, including the two-column homepage and the Micro.blog RSS functionality.

The type is set in [Inter](https://fonts.google.com/specimen/Inter?query=inter) by Rasmus Andersson and [Zilla Slab](https://fonts.google.com/specimen/Zilla+Slab?preview.script=Latn) by Typotheque and is served by [Google Fonts](https://fonts.google.com/). Icons throughout the site are served by [Font Awesome](https://fontawesome.com/).

Inspired by [Mandy Brown](https://aworkinglibrary.com/), I use [Micro.blog](https://micro.blog/) to syndicate notes to various social media platforms, and [EmailOctopus](https://emailoctopus.com/) for sending newsletters of my posts.
